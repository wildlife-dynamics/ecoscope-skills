# ecoscope-skills

Claude Code plugin marketplace for Ecoscope workflow development.

- `plugins/ecoscope/` — the main plugin: skills for developing, publishing, and reviewing
  Ecoscope workflows, plus the shared knowledge base at `plugins/ecoscope/reference/`.
- `plugins/ecoscope-guards/` — optional companion plugin carrying hooks (installing it is the
  opt-in).

Full README and marketplace manifests land after the suite is reviewed (build order step 7).
